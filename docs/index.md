# We

**We** is a private, guild-specific Discord bot with one artistic purpose:
every manageable member of one Discord server (guild) carries the same guild
nickname —

> **We**

Any later deviation is reconciled back to **We**.

The bot changes **guild nicknames** only. It cannot and does not change
anyone's account-wide Discord display name, it never reads messages, and it
never acts outside the single server it is configured for.

It is installed by invitation only and operates in exactly one server chosen
by its operator.
